# C02. Корпус и воспроизводимые метрики

Дата: 2026-10-03.

**Статус: instrument implemented, external review blocked.** Инженерная часть C02 завершена: подготовлены замороженный источник, manifest на 200 продуктов, независимый final-набор, шаблон слепой ручной разметки, раздельный измеритель и тесты. Итоговый OCR-бенчмарк не validated: независимая ручная расшифровка фотографий составляет 0/100 и не подменена текстом каталога.

Другие completion-задачи не выполнялись. Runtime приложения, UI, API, база, авторизация, Telegram и деплой не изменены.

## Реализовано

- `scripts/build-c02-corpus.mjs` получает кандидатов из Open Beauty Facts только по явному `--refresh`, сохраняет локальный snapshot, а обычный запуск строит корпус офлайн из этого снимка.
- `scripts/lib/c02-corpus.mjs` формирует ровно 200 записей, сохраняет неизвестные поля как `null`, создаёт отдельные аннотации и проверяет пригодность ручной записи для gold-метрик.
- `audit/c02/source-snapshot.json` содержит 227 подходящих исходных записей. Manifest детерминированно выбирает 200: 150 setup и 50 final.
- Final изолирован по нормализованному основному бренду. Один split-group не может попасть одновременно в setup и final; это консервативно удерживает близкие версии одного бренда в одной части.
- Для каждого кандидата сохранены штрихкод, source-reported название/бренд/категории/рынки, фото состава, при наличии лицевая фотография, URL карточки/API, дата изменения источника, происхождение и лицензии.
- Назначение, проверенная категория, полнота формулы, рынок и дата упаковки не угадываются: до ручной проверки соответствующие reviewed-поля равны `null`.
- Каталожный `ingredients_text` явно помечен `external_catalog_transcription_not_gold` и исключён из OCR-метрик.
- `docs/C02_ANNOTATION_GUIDE.md` задаёт слепую ручную расшифровку без просмотра OCR, каталожного текста и ответа анализатора. Неполные approved-записи fail closed и не входят в gold.
- `scripts/run-c02-evaluation.mjs` независимо измеряет качество корпуса, подтверждённую идентификацию, полноту формулы, OCR, распознавание справочника и экспертное покрытие.
- Добавлены фиксированные кейсы медицинской ошибочной классификации, списка только активов и двух конфликтующих формул, которые запрещено смешивать.

## Внешние блокеры

1. Независимый рецензент должен вручную расшифровать минимум 100 фотографий по `docs/C02_ANNOTATION_GUIDE.md`. До этого OCR precision/recall не вычисляются.
2. В репозитории нет локального архива фотографий: сохранены 200 проверяемых URL Open Beauty Facts с лицензией CC BY-SA. Для устойчивого бенчмарка фотографии нужно архивировать с атрибуцией либо сохранить иным допустимым способом во время ручной разметки.
3. Назначение, полнота и категории должны быть подтверждены человеком. Автоматические source/category-подсказки не повышаются до gold.
4. Final-набор нельзя открывать разработчикам правил/OCR до завершения настройки на setup.
