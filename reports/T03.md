# T03 — Принадлежность состава товару

## Что изменено

- Поисковый текст отделён от выбранной карточки товара во внутреннем состоянии клиента.
- Для состава фиксируется источник: карточка товара, ручной ввод или фото.
- Редактирование названия инвалидирует выбранную карточку, автоматически
  подставленный INCI и старый результат.
- Ручной и полученный с фото состав при редактировании поиска сохраняются.
- Перед заменой независимого ручного/фото-состава составом карточки требуется
  подтверждение пользователя.
- Карточка без INCI очищает прежний автоматически подставленный состав товара,
  но не удаляет независимый ручной состав.
- Запоздалые ответы поиска и загрузки деталей проверяются по номеру актуального
  запроса и не применяются к уже выбранному товару.
- Очистка поиска отменяет активный запрос и запрещает позднему ответу вернуть
  подсказки или старый INCI.
- Отправка формы с одним только поисковым текстом больше не выбирает первый
  результат автоматически: пользователь должен нажать нужную карточку.
- Новый снимок без уверенно определённого товара снимает принадлежность состава
  с ранее выбранной карточки.

Маршруты API, серверная модель данных, анализатор, авторизация, Telegram и
деплой не изменялись.

## Проверки

```powershell
npm.cmd run test:t03
npm.cmd run test:t02
npm.cmd test
npm.cmd run check
node --check public/app.js
```

`test:t03` использует только локальные детерминированные моки и проверяет:

- A -> ввод B без отправки состава A;
- медленные ответы поиска A и деталей A после выбора B;
- очистку поля во время незавершённого поиска/загрузки;
- обязательный выбор между двумя похожими товарами;
- карточку без INCI после карточки с INCI;
- подтверждение замены ручного состава, в том числе введённого во время загрузки;
- независимый новый фото-состав.

Мок фото проверяет только состояние интерфейса и не считается проверкой OCR.

## Ограничения

- Формальный сквозной контракт достоверности и сохранение идентичности товара на
  сервере относятся к T04 и здесь не добавлялись.
- Качество поиска, OCR, штрихкодов и внешних источников не изменялось.
- При сохранении независимого ручного состава выбранная карточка остаётся
  видимой, а статус явно сообщает, что INCI карточки не подставлен.
