# T01 — Regression baseline

## Scope

This task adds deterministic regression coverage only. No application feature,
route, design, authentication flow, deployment configuration, or production
data was changed.

## Commands

Normal offline checks, expected to pass on the T01 baseline:

```powershell
npm.cmd test
npm.cmd run check
```

Known-defect regression suite, intentionally red before the remediation tasks:

```powershell
npm.cmd run test:regressions
```

The second command runs Node unit checks and a 390 px Playwright browser check
against a local static server. The browser suite intercepts API calls with
declared fixtures; it neither contacts external services nor represents mocked
camera/OCR results as genuine recognition.

## Current status and limits

`npm.cmd test` remains the green baseline. `npm.cmd run test:regressions` is
expected to fail until its listed remediation tasks are implemented; its EAN
trailing-line case already passes and remains a regression guardrail. The other
failure messages explain unsafe current behaviour, rather than treating it as a
passing fixture.

The test suite proves only deterministic local transformations and mocked
browser responses. It does not validate accuracy of third-party product data,
real device camera permissions, a real OCR engine, formula concentrations, or
clinical safety. Those require the source-specific and human-review workflows
defined by later tasks.
