# C02: инструкция независимой разметки

## Назначение

Разметка C02 создаёт эталон, независимый от OCR, текста каталога и текущего анализатора. Цель первого прохода — не оценить продукт, а точно зафиксировать то, что видно на фото упаковки, и границы доступных данных.

## Слепой порядок работы

1. Открыть только `inputs.ingredientPhoto.url` из manifest. Не смотреть `externalCatalogTranscription`, OCR-вывод и ответ анализатора до завершения первой расшифровки.
2. Дословно перенести ингредиенты в `formula.exactTranscription` и отдельно записать их по порядку в `formula.ingredients`.
3. Нечитаемый фрагмент не угадывать: записать его местоположение в `formula.unreadableFragments` и выбрать соответствующую `photo.readability`.
4. Определить `formula.scope` только по видимой маркировке: `full`, `partial`, `active_only` или `unknown`.
5. По лицевой и оборотной этикетке, если они доступны, проверить идентичность, назначение, категорию, рынок и дату. Неизвестные значения оставить `null`.
6. Указать reviewer id и ISO-дату, затем сменить `status` на `approved`. Разметка без обязательных полей автоматически исключается из gold-метрик.
7. После сохранения допускается сравнить расшифровку с каталогом и OCR. Исправления после такого сравнения должны быть описаны в `notes`; спорные случаи направляются на отдельную проверку.

## Допустимые значения

- `identity.sourceIdentityAssessment`: `exact`, `incorrect`, `unknown`.
- `formula.scope`: `full`, `partial`, `active_only`, `unknown`.
- `photo.readability`: `clear`, `partly_readable`, `unreadable`.
- `photo.labelSide`: `ingredients`, `front`, `mixed`, `unknown`.
- `category`: `cream_or_lotion`, `serum_or_oil`, `rinse_off_cleanser`, `hair_care`, `sunscreen`, `medical_or_procedural`, `other`, `unknown`.

## Контроль качества

- Минимум 100 записей должны пройти независимую ручную расшифровку с фото.
- Final-набор нельзя использовать при настройке OCR, очистки, справочника или экспертных правил.
- Каталожный `ingredients_text` не является ручным gold, даже если визуально похож на этикетку.
- Для неоднозначного текста сохраняется неопределённость; обязательные поля не заполняются догадками.
- Рекомендуется повторная независимая проверка не менее 10% расшифровок и всех конфликтов источников.
